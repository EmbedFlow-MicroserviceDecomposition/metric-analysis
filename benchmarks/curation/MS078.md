## Runtime route check (2026-11-18)
No published images exist, so a full-stack run would mean building 4 images, running SQL Server and generating certificates, and driving the OIDC login with a headless browser. Even then the SPA's requests come from the user's browser, so they can't be tied to the wallet-spa container on the network. So the check targets the weakest static assumption instead: **does each SPA request, sent exactly as written, reach the action the ground truth names?** (This covers the lowercase paths against `[controller]`/`Deposit` routes in D10, API versioning, and `FormData` bodies against `[FromForm]` parameters.)

**Setup:** accounts-api built from source (`src/WebApi/Dockerfile`, arm64) and run alone using the application's own feature switches: `FeatureManagement__Authentication=false` (built-in `TestAuthenticationHandler`), `FeatureManagement__SQLServer=false` (in-memory fake), `FeatureManagement__CurrencyExchange=false` (built-in fake). `route_check.sh` sends the 7 requests from `src/store/*.js` with their literal lowercase paths and `multipart/form-data` bodies (the pages build `FormData`), then reads ASP.NET's `Executing endpoint '…'` log line for each. Evidence is in `MS078_runtime/`.

| SPA function | Request | Routed to (ASP.NET log) | GT dst |
|---|---|---|---|
| getAccounts | `GET /api/v1/accounts` | `V1.Accounts.GetAccounts.AccountsController.Get` | ✅ |
| getAccount | `GET /api/v1/accounts/{id}` | `V1.Accounts.GetAccount.AccountsController.Get` | ✅ |
| openAccount | `POST /api/v1/accounts` | `V1.Accounts.OpenAccount.AccountsController.Post` | ✅ |

All 7 returned HTTP 200, and a script compared each routed action with the ground truth's `dst_class.method_name`: 7/7 match.

**Limit:** this confirms destination resolution, not that the browser issues the calls (that part is literal in `src/store/*.js`); OIDC and identity-server were not exercised.

**Checker hardening during this round** (`scripts/verify_ground_truth.py`; MS032/MS020 re-verified, still pass): evidence snippets must be backtick-free (JS template strings had truncated the check); entry-point detection reads the first real signature line after stacked attributes, `#pragma` and comments; entry points are counted per class+method so overloads can't mask each other; Feign-style client mappings are skipped only in the caller's own client file; C# `httpClient.*Async(` calls are outbound sites. Mutation suite: 17/17 deliberately broken ground truths caught across MS032, MS020 and MS078.

**Known Gate C limit:** convention-routed MVC actions without `[Http*]` attributes (Home.Index/Error, Diagnostics.Index) are not grep-detectable; they were found by reading the controllers and are confirmed by the blind extraction.
